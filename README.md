# Handwritten Character Recognition Using CNN

## CodeAlpha Task 3 — Handwritten Character Recognition

**Name:** Sanika Rangra

**Project:** Handwritten Digit Recognition Using Convolutional Neural Network

## Objective

The objective of this project is to identify handwritten digits from image data using a Convolutional Neural Network (CNN).

## Dataset

The project uses the MNIST handwritten digit dataset provided through TensorFlow/Keras.

The dataset contains:

- 60,000 training images
- 10,000 testing images
- Image size: 28 × 28 pixels
- 10 classes representing digits from 0 to 9

The MNIST dataset is automatically downloaded when the notebook is executed.

## Approach

The project follows an image classification workflow:

1. Load the MNIST dataset
2. Explore and visualize handwritten digit images
3. Analyze class distribution
4. Normalize pixel values
5. Reshape images for CNN input
6. Build a Convolutional Neural Network
7. Train the CNN
8. Evaluate the model on the test dataset
9. Calculate Accuracy, Precision, Recall, and F1-Score
10. Generate a confusion matrix
11. Visualize model predictions
12. Analyze misclassified images
13. Save model evaluation results
14. Save the trained CNN model

## CNN Architecture

The implemented CNN consists of:

- Convolutional layer with 32 filters
- Max Pooling layer
- Convolutional layer with 64 filters
- Max Pooling layer
- Flatten layer
- Dense layer with 128 neurons
- Dropout layer
- Output layer with 10 classes

ReLU activation is used in the hidden layers and Softmax is used in the output layer.

## Data Preprocessing

The image pixel values originally range from 0 to 255.

They are normalized to the range 0 to 1 before being provided to the CNN.

The images are reshaped from:

28 × 28

to:

28 × 28 × 1

where 1 represents the grayscale channel.

## Model Training

The CNN is trained using:

- Optimizer: Adam
- Loss Function: Sparse Categorical Crossentropy
- Batch Size: 64
- Epochs: 10
- Validation Split: 10%

## Evaluation Metrics

The model is evaluated using:

- Accuracy
- Precision
- Recall
- F1-Score
- Confusion Matrix

Training and validation accuracy and loss curves are also generated to analyze the learning process.

## Prediction Analysis

The project visualizes:

- Correctly and incorrectly predicted handwritten digits
- Misclassified images
- Actual versus predicted labels
- Confusion matrix

This provides a visual understanding of the CNN's classification performance.

## Results

The actual test accuracy, precision, recall, and F1-score generated by the notebook are reported in the notebook and saved in:

`mnist_cnn_results.csv`
